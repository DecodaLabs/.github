**Decoda** is an AI-powered malware analysis platform built for security analysts, threat hunters, and malware researchers. Upload a sample, and Decoda's AI agents handle the rest - from static and dynamic analysis through to full reporting.

### What Decoda does

- **Automated triage and classification** - YARA rules, heuristics, and AI-driven threat scoring on every sample
- **Deep static analysis** - Disassembly, decompilation, and structural analysis powered by Ghidra and custom tooling
- **AI agent workflows** - Conversational analysis where you ask questions about your samples and get structured, sourced answers
- **.NET and script analysis** - Dedicated pipelines for managed code, PowerShell, Python, and other scripted threats
- **Structured reporting** - Export-ready reports for SOC handoff, threat intelligence feeds, or internal documentation

### Built by practitioners

Decoda is built by [CLU Systems](https://clusystems.com) - a cybersecurity software company founded by a working threat researcher. The product is shaped by real-world analysis workflows, not abstract feature lists.
